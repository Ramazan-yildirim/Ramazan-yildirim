# Terminal profile assets

Run `node scripts/build-terminal-assets.mjs` from this repository. The generator has no dependencies and rebuilds:

- Wide/compact logo-only headers using the original RY silhouette and its 1,708 small white square cells. `ry-grid.json` is the original 88×58 sample, preserved without changing the letter shapes. Compared with the initial treatment, cells are slightly fuller, silver depth is reduced to four pixels (three in compact), and placement is centered on the occupied cell bounds. Light variants have a slightly stronger outline. The background stays transparent; the original brand mark is retained in `assets/brand/ry.svg`.
- Wide/compact About Me and Dijital Diş Dünyası panels. About Me uses an 18-row ANSI block-character Tux, a shell prompt, aligned profile fields and an eight-color ANSI strip. Tux has a slate silhouette, light eyes and belly, and an amber beak and feet. The wide layout puts Tux beside the profile; the compact layout keeps a small Tux and name above the stacked fields. Profile content is unchanged.
- Compact bracket-style link buttons in dark/light variants and technology package cards. All links share the same neutral style and transparent background. Links are 36px high, with vector arrows and separate clickable README targets.
- CV/portfolio downloads use explicit `download` labels and downward arrows. CV and portfolio previews have independent native `<details>` sections stacked vertically inside separate centered one-cell HTML tables. Each cell supplies a shared border around the native arrow and the label, including the preview content when expanded. Left-aligned, non-wrapping cells put the native arrow at the left edge of the button. Each summary contains only inline monospace `<samp>` text, so GitHub adds no image links or themed-picture wrappers. Non-breaking spaces align the label separator, and native text follows GitHub's active color theme. An inner left-aligned container preserves the content layout. No script, SVG label, page-level CSS or external hosting is required.

Edit the content, palette and geometry in `build-terminal-assets.mjs`, then regenerate the SVG files. The technology icons remain embedded, so they need no external requests. The original brand assets are retained.

About Me has a CSS-only terminal opening animation on each image load. After a 0.35-second pause, `whoami` types one character every 0.14 seconds with a following block caret. Tux and the profile appear at 1.35 seconds; the lower shell prompt appears at 1.55 seconds with a blinking green cursor. Starting at 4 seconds, Tux raises its left flipper, waves it twice, then rests; this greeting repeats every 4 seconds. The gesture lasts 1.26 seconds, independently of the repeat interval. Only the outer flipper rotates, with a fixed inner body column and layout-specific shoulder pivot. Edit `aboutMotion` for the timing and the `waveFrames` time/angle pairs for the gesture. Both layouts use the same sequence, with no JavaScript, external requests or scheduled regeneration. Reduced-motion preferences show the complete static profile and a steady cursor immediately; renderers without animation support also retain the full profile.

The About Me and Dijital Diş Dünyası panels use macOS-style title bars with red, amber and green window dots. The Dijital Diş Dünyası section has a centered original logo with the Co-Founder & Developer role and a short description underneath. Both layouts use the same vertical arrangement: the wide card is 900×236 and the compact card is 360×236. A separate centered website button below the card links to the platform. Feature and audience lists are omitted.

All technology cards are visible in the three stack groups. TensorFlow belongs with AI/computer vision; HTML5 and CSS3 belong with backend/web; PowerShell and GitHub belong with tools. There is no separate Other technologies disclosure. C# and .NET remain omitted.

Profile panels retain their dark terminal surface. Headers and link buttons select explicit light/dark variants through README `<picture>` elements; the Vercel statistics service also supports explicit dark/light palettes. Compact headers and panels are selected below 600px. The wide logo header is 900×304; the compact header is 360×236. Both use the original silhouette with different cell sizes. The six top links total 788px before spacing and wrap naturally on smaller screens. Separate `CV --en` and `CV --tr` buttons download the English and Turkish PDFs; each has light/dark variants and a downward arrow. CV and portfolio previews use GitHub's native disclosure immediately below the top link buttons. C# and .NET are omitted from the README technology list. Edit `aboutFields` to update the profile content; both layouts and the SVG description share those values. About Me is 900×436 on desktop and 360×631 in compact form. Edit `tuxRows` to adjust its character-art penguin: spaces are empty cells, `K` is slate, `W` is light, `Y` is amber and `P` is a dark pupil. The renderer turns occupied cells into `█` runs with explicit positions and widths, and disables ligatures to keep the terminal grid aligned across monospace fonts. No external image or font request is required.

PDF links retain their existing raw GitHub targets. Opening a PDF automatically after it downloads is controlled by the viewer's browser or PDF application; README markup cannot disable that preference.

The GitHub stats service lives in the sibling `ramazan-github-stats` repository. Its SVG templates and palettes are in `lib/cards.js`; data fetching, endpoint options and cache behavior are unchanged. Both stats cards use macOS-style window dots. Activity follows the supplied dashboard reference with the same flat background and panel colors as the other cards, three inset ring panels, a larger central streak ring and three small icon panels below. The contribution and year rings are smaller than the streak (50px versus 64px on desktop, 30px versus 40px on mobile). Languages retain the minimal donut card with a color-matched legend. Open `previews/github-stats/index.html` for a local snapshot preview in both themes and screen sizes. Deploy the stats repository to update the live statistics images. The contribution snake picks up the new palette on the next workflow run after publishing this profile repository.
